### FitTrack AI — AI-Powered Fitness Coaching Platform
 
Full-stack fitness platform combining real-time computer-vision exercise tracking with an LLM-driven adaptive coaching engine.
 
**[Live Demo](https://fit-track-ai-sooty.vercel.app/)** · **[Source](https://github.com/AnchitCode/FitTrack-AI)**

### MASAS — Geospatial Medicine Search & Pharmacy Platform
 
Location-aware platform for real-time medicine availability, connecting patients to nearby pharmacies via geospatial search — built to a production standard, not a prototype.
 
**[Source](https://github.com/AnchitCode/masas-platform)**
 
- **PostGIS**-backed geospatial queries (`ST_DWithin`) for location-based pharmacy and medicine discovery
- API-versioned REST layer documented with **OpenAPI/Swagger** across 19 endpoints
- **92/92 integration tests passing**, run in Docker via GitHub Actions CI/CD
- Type-safe data layer with **Prisma ORM** over PostgreSQL, deployed on NeonDB + Vercel
`React` · `TypeScript` · `Node.js` · `PostgreSQL` · `Prisma` · `PostGIS` · `Docker` · `GitHub Actions`
